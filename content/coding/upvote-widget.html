Upvote Widget

This is a little widget that lets visitors upvote/like content on your website. Each button can have its own unique number, or you can add multiple buttons for the same counter. It can be styled however you like. This widget uses cookies to remember who has already upvoted, so multiple upvotes are not possible. It is also possible to unlike.

How to use

To use the upvote widget, simply include the following script:

<script src="https://petrapixel.neocities.org/assets/js/upvote-widget.js?nocache=1"></script>

and create the widget like so:

<div class="upvote-widget" data-upvote-widget="ADD-UNIQUE-ID-HERE">
  <button type="button">Upvote</button>
  <span>0</span>
</div>

Make sure to replace ADD-UNIQUE-ID-HERE with a unique identifier for each widget that you want to have a unique upvote count. Two widgets with the same ID on the same website will have the same upvote count.

You can then style the widget however you want. The button will be disabled if a visitor has already upvoted. The number of upvotes will be displayed in the span element, which you can also move into the button if you want.

The widget will get the attribute data-upvoted after a user has upvoted it.

Here is some simple example styling you can adjust for your preferences: 

.upvote-widget button {
  background: rgb(255, 165, 165);
  border: 1px solid rgb(146, 17, 17);
  padding: 4px 10px;
  border-radius: 4px;
  font-size: 20px;
}

.upvote-widget button:not(:disabled):hover {
  filter: brightness(0.9);
}

/* after upvote: */
.upvote-widget[data-upvoted] button {
  color: rgb(102, 0, 0);
  background: rgb(244, 154, 154);
}

If you want to disable unliking, you can add this:

.upvote-widget[data-upvoted] button {
  pointer-events: none;
}

If you want to change "Like" to "Liked" or "Upvote" to "Upvoted" for if a user already clicked it, you can do this: 

.upvote-widget[data-upvoted] button::after {
  content: "d";
}
