Responsive CSS Tutorial

Making your website responsive means making it function and look good on devices of all sizes, including mobile phones and tablets. And it's easier than you think!

Making your website responsive also increases the accessibility of your website, because some people don't have a computer! Also, most people use their phones to browse the web. (Yes, most!) Even if you don't care about modern web design or mobile browsers, you should still make your website responsive. Saying "it's too hard" or "i'm lazy" is not an excuse. Especially since just a small changes will cover 90% of the work! This tutorial will show you how.

Keep in mind: A small screen does not always mean a mobile device. For example, users can resize their browser window to be really small. It's also possible to view the desktop version of your website on phones because mobile browsers often have a "show desktop site" function.

Hello mobile user! I highly recommend viewing this tutorial on a desktop device, because otherwise you can't easily see the difference between the desktop and mobile examples!

Basics

HTML

To start off, you need this line in your HTML head (anywhere between <head> and </head>):

<meta name="viewport" content="width=device-width, initial-scale=1.0" />

This will make sure your website resizes depending on screen size.

Now let's see how we can make this smaller version of our website look good!

Units

A good habit to get into is to use responsive units of measurement in your CSS code. That way, the sizing and positioning of your elements will automatically look good on different screen sizes.

For example, use % instead of px for the sizing of an element or the positioning of an absolute element.

Check out this example, try resizing your browser window:

width: 50%;

You might also want to use these cool units:

  • vw: 1% of the browser width
  • vh: 1% of the browser height

For example, giving an element width: 50vw; will make it half as wide as the browser. Try resizing your browser window:

width: 50vw;

Max-width

Another thing you should absolutely do is work with max-width, min-width, max-height, and min-height.

For example, instead of giving your main content a fixed width with something like width: 800px;, use width: 100%; max-width: 800px; so it does not extend the screen width on small screens but does scale to 800px width on large-enough screens.

These two look the same on a large screen, but try making your browser smaller and see the difference:

width: 800px;
width: 100%;
max-width: 800px;

This is by far the easiest way to make your website more responsive, so remember it!

CSS Media Queries

Basic Usage

Of course there is another way to make your website more responsive: CSS Media Queries. I swear they're super easy.

This is what media queries can look like:

.example {
  color: red; /* Text will be red by default */
}

@media (max-width: 500px) {
  .example {
    color: blue; /* Text will be blue on screens smaller than 500px */
  }
}

@media (min-width: 1200px) {
  .example {
    color: green; /* Text will be green on screens larger than 1200px */
  }
}

These are the most basic media queries, but you can do more with them, like checking whether a screen is taller than it's wide ((orientation: portrait)), or checking for both a width and a height ((min-width: 300px) and (max-width: 500px)), but you probably won't need those often. Here is the official documentation on media queries if you want to learn more about them.

Learn more about creating responsive grids.

Example 1: Font size

Here is a small example on how to control font size depending on screen size. Here I make use of the em unit to define the heading's font size as 1.5em. Here's how it works: 1em is the base font size that is defined in a parent element. Setting it to 1.5em will make it 1.5 times larger, 2em will make it twice as large, and so on - no matter what the base font size is! This way, we only need to adjust the base font size per screen size, not all font sizes.

Headline Example (1.5em)

Paragraph Example (1em)

.example {
  font-size: 18px; /* text is 18px by default  */
}

.example h1 {
  font-size: 1.5em; /* headline is always 1.5 times larger than the normal text */
}

@media (max-width: 800px) {
  .example {
    font-size: 15px; /* text is 16px on smaller screens */
  }
}

@media (max-width: 600px) {
  .example {
    font-size: 12px; /* text is 14px on even smaller screens */
  }
}

This only requires a bit of knowledge about flex and grid layouts. (I explain both of them in my other CSS tutorial: Flexbox and Grid.) All we need is some simple layout code and a single media query:

.wrapper {
  display: grid;
  grid-template-columns: 100px 1fr; /* 2 columns */
}

.navigation {
  display: flex;
  flex-direction: column; /* vertical flexbox */
}

@media (max-width: 600px) {
  .wrapper {
    grid-template-columns: 1fr; /* change to 1 column layout */
  }

  .navigation {
    flex-direction: row; /* change to horizontal flexbox */
    flex-wrap: wrap; /* allow wrapping text into next line */
  }
}

Add a little bit of styling for color, paddings, margins, borders etc. and boom - you're done!

Testing

I've already told you that you can simply resize your browser window to view what your website would look like on smaller screens. But there's an even better way of testing! In your browser's development tools (which you should already be using!) there is a button that enabled a preview mode where you can easily change the apparent screen size (you can even select phone model presets on the top!) without resizing your entire browser window. You do this by dragging the bottom right edge of the preview.
